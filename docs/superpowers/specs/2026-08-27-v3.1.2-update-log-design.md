# V3.1.2 更新日志设计

## 目标

将网页打开时弹出的更新日志从 V3.1.1 替换为 V3.1.2，只展示最新版本内容，让用户能直接了解新预言功能和三张正式服核心卡的数值调整。

## 弹窗结构

保持现有弹窗样式和交互，仅更新标题与日志条目。内容顺序为：

1. 永久地址
2. 预言功能
3. 卡牌调整
4. 作者「寄」语

旧版的“时代服”、“正式服”和“模拟器”条目不再显示。

## 日志文案

### 预言功能

- 支持记录已猜中的预言牌及重复次数
- 推荐区显示可触发的免费刷新次数
- 推荐排序优先信息增益，再比较刷新次数
- 切换拓展包时清空预言记录

### 卡牌调整

- 凶残巨兽：单位数 1，战力 500
- 地雷禁区：单位数 2，战力 300
- 虚空大军：单位数 6，战力 950

“永久地址”和“作者「寄」语”保持现有文案。

## 交互与兼容性

- 继续在用户当天首次打开网页时自动显示更新日志。
- 用户选择“今日关闭”后，当天不再自动弹出。
- 顶部铃铛按钮仍可随时重新打开弹窗。
- 不修改现有 `localStorage` 键或弹窗关闭逻辑。

## 验证

在现有 Node.js 测试中增加更新日志断言，确认：

- 弹窗标题为 `V3.1.2 更新日志`
- 预言功能的关键文案存在
- 三张卡牌的新数值均出现在弹窗中
- 永久地址和作者寄语仍然保留
- V3.1.1 专属的旧日志条目不再出现
