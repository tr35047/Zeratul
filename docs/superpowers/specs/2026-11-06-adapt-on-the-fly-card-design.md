# “随机应变”正式服核心卡设计

## 目标

向正式服核心包新增卡牌“随机应变”。

## 卡牌数据

- 名称：随机应变
- 种族：中立（`Neutral`）
- 等级：6
- 单位数：5
- 战力：3000

## 范围与行为

- 仅修改正式服核心数据 `resource/data/core.js`。
- 不修改亚服核心数据；亚服不得出现“随机应变”。
- 该卡作为普通核心卡，正常出现在记牌器与模拟器中。
- 该卡可以成为预言牌并参与推荐计算。
- 不修改版本号、更新日志或其他卡牌。

## 验证

- 先新增失败测试，验证正式服存在且字段准确，并验证亚服不存在。
- 修改正式服核心数据后运行相关测试与完整测试套件。
- 上传前检查 Git 差异和远端快进关系。
