# 嘉年庆典与 V3.1.5 设计

## 目标

为正式服新增普通拓展包“嘉年庆典”，修正一张正式服核心卡名称，并发布精简的 V3.1.5 更新日志。

## 卡包与数据

- 新卡包键名为 `pack12`，显示名为“嘉年庆典”，数据文件为 `resource/data/pack12.js`。
- 只注册到正式服 `PACK_REGISTRY`，不修改亚服或时代服注册表及数据。
- 卡包包含四张卡：
  - 及时支援：人族，2 本，单位数 6，战力 300。
  - 暗色血裔：中立，3 本，单位数 1，战力 500。
  - 重置与决定：星灵，4 本，单位数 7，战力 2450。
  - 问了没啊：异虫，6 本，单位数 16，战力 775。
- 该卡包按普通拓展包处理：在记牌器和模拟器中按真实种族与等级显示，可作为进场卡并参与推荐。
- 预言牌池继续只使用核心包，嘉年庆典卡牌不能成为预言牌。

## 卡牌更名

- 仅修改正式服 `resource/data/core.js`。
- 将异虫 6 本、单位数 1、战力 2000 的“凶猛巨兽”更名为“利维坦”。
- 亚服与时代服中的“凶猛巨兽”保持不变。

## 版本与更新日志

- 页面标题和更新日志标题升级为 `V3.1.5`。
- 更新日志只保留以下区块：
  - 永久地址。
  - 卡牌更新：新增“嘉年庆典”拓展包及四张卡；“凶猛巨兽”更名为“利维坦”。
  - 红色提示：“切换拓展包时清空预言记录”。
  - 作者「寄」语。
- 删除 V3.1.4 中的“预言功能”和“特殊卡牌”区块。

## 缓存与文档

- 更新相关静态资源缓存版本，确保正式网页获取新数据与页面内容。
- README 同步 V3.1.5、正式服可选卡包、目录树和卡牌数量。

## 验证

- 数据测试验证四张新卡的种族、等级、单位数和战力。
- 数据测试验证正式服已更名为“利维坦”，亚服和时代服仍为“凶猛巨兽”。
- 集成测试验证 `pack12` 仅注册在正式服、页面版本为 V3.1.5、更新日志仅包含批准内容且提示为红色。
- 浏览器验证记牌器与模拟器均能启用嘉年庆典并正确筛选四张卡。
- 完整测试通过后提交并快进推送到 GitHub `main`。
